# ♟ Xeque Malte

Um projeto de site/blog sobre xadrez, estratégias e curiosidades, desenvolvido com uma identidade visual inspirada em um clube de xadrez contemporâneo.

O projeto busca fugir da estética tradicional de sites esportivos e criar uma experiência mais editorial, aconchegante e moderna.

## 📸 Preview

![Preview do projeto](assets/preview.png)

## 🚀 Sobre o projeto

O Xeque Malte é um blog desenvolvido para reunir conteúdos relacionados ao universo do xadrez.

A estrutura do site é organizada de acordo com as principais fases de uma partida:

- ♟ Abertura
- ♞ Meio-jogo
- ♜ Finais

Além disso, o projeto conta com:

- Artigos sobre xadrez
- Desafio do dia
- Navegação por categorias
- Newsletter
- Layout responsivo

## 🎨 Design

A identidade visual utiliza uma paleta inspirada em madeira, malte e ambientes aconchegantes.

Principais cores:

- Preto: `#1c1410`
- Marrom escuro: `#2e2015`
- Marrom médio: `#6b4423`
- Amarelo: `#f2a93b`
- Branco: `#f5f1e8`

As fontes utilizadas são:

- **Fraunces** — títulos
- **Inter** — textos e interface

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts

## 📱 Responsividade

O projeto possui adaptação para diferentes tamanhos de tela, incluindo desktop, tablet e dispositivos móveis.

## 💡 Funcionalidades

Atualmente, o projeto possui:
